Install 3DJames on Windows

There are two ways to use 3DJames on a Windows PC. Both are the same app and open the same .3dj projects.

  • The installer (3DJames-Setup.exe): 3DJames becomes a normal Windows app with its own window, a Start menu entry and an Installed apps entry.
  • The 3DJames folder (for example downloaded from the 3DJames page on GitHub with Code > Download ZIP): unzip it anywhere and double-click 3DJames.html or Open 3DJames.cmd. It opens in your web browser, and nothing is installed. It doesn't update itself: download it again for a newer version.

Install

  1. Double-click 3DJames-Setup.exe.
  2. If Windows says Windows protected your PC, click More info, then Run anyway. Windows says this about any app that isn't signed with a paid certificate.
  3. Choose Install for me only (no administrator needed) or for everyone on the PC. Tick Create a desktop shortcut if you want one, and click Install.
  4. Click Finish: 3DJames opens. Next time, start it from the Start menu (3DJames) or the desktop shortcut.

The app needs Microsoft's WebView2, which Windows 10 and 11 normally already have. If it is missing, 3DJames says so and offers to open Microsoft's download page. After that, everything works without the internet.

Your files

  • Save and Open use the normal Windows file windows, so you choose where projects go. The installer makes a Documents\3DJames\Projects folder for them; an AI helper saves there too (see Let an AI help).
  • Backups and settings of the installed app are kept apart from the browser's: projects you only had in the browser's backups don't show up in the app. Save them as .3dj files first, then open them in the app.

Let an AI help in the installed app

The installed app has 3DJames Link built in. After installing Antigravity, open the Start menu, go to 3DJames and click Connect Antigravity to 3DJames (once). Then restart Antigravity. The rest is the same as in Let an AI help.

Update or remove

  • Updates come by themselves. A few seconds after 3DJames starts, the installed app looks on GitHub for a newer version. If there is one, it downloads it quietly and tells you; the new version opens the next time you start 3DJames. Nothing of yours is sent: it only asks GitHub for two files. If you are offline, nothing happens.
  • To look right now, or to turn the automatic look off, open Help > Licenses and components: the Updates box has the switch and a Check now button.
  • Running a newer 3DJames-Setup.exe works too. It replaces the old version and keeps your projects and settings. Only the app itself updates by itself: other files, such as the AI link program, come with a newer 3DJames-Setup.exe.
  • To remove it: Windows Settings > Apps > Installed apps > 3DJames > Uninstall, or Uninstall 3DJames in the Start menu. Your saved projects stay where they are.
