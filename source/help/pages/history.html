History, variables and versions

Everything you do is kept as a list of steps, so a design is never "finished": go back to any step and change it, and everything after it follows. Variables let one number drive many sizes, and versions keep named milestones inside your project.

History

Open the History tab of the side panel (or View > History). Pick an object and choose This object to see how it was made, including the shapes cut out of it or merged into it; All steps lists every step in the project.

  • Click a step to open its settings, change them, and the model rebuilds.
  • Give a step a name, so you find it again (Step name).
  • Turn off a step to see the model without it; its settings are kept. Turning off an operation can change faces or edges used by later steps.
  • Earlier / Later move a step in the list, when the steps that depend on it allow it. The step shows what it depends on.
  • Delete step: when later steps depend on it, you choose to delete only this step or it and the steps that depend on it. Both can be undone.
  • A step that can't be built shows at the top of the list with Edit, Turn off and Delete step, so you can fix it.

Variables

At the bottom of the History tab, under Variables, click + to add one. Name a number once, like wall = 2, then type wall (or wall*2, wall+0.4) into any size box in Properties. Change the variable, and every size that uses it changes. A variable can use the ones above it in the list (inner = outer - 2*wall). A red box means the formula can't be worked out.

Versions inside a project

☰ > Save as new version… keeps a named snapshot (with a note, if you like) and saves the project. Ordinary Save just updates your working model; it doesn't make a new version each time. The first time, an earlier saved model that differs is kept as "Previously saved".

☰ > Select version… lists the snapshots. Restore brings one back as the working model (the list is kept); Delete version removes one. Both can be undone; save the project to keep the change.

Versions are kept in .3dj files, and in editable 3MF and JSON saves. Up to 200 versions per project and 400 MB per file: delete old versions if needed. They are separate from the automatic Backups.
