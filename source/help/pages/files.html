Saving and opening

Everything is in the File menu (☰) at the top left. Saving makes every kind of file: your editable project, or a file for your slicer or another CAD program.

Save and open projects

  • Save (Ctrl+S) keeps your project as a .3dj file: every step stays editable, with its versions and imported files.
  • Save as… (Ctrl+Shift+S): pick the place, the name and the type: a 3DJames project (.3dj), 3MF, STL or STEP (see below).
  • Open… (Ctrl+O): 3DJames projects, STEP, 3MF, OBJ and STL. You can also drop a file on the window. New starts an empty project. An STL, OBJ or 3MF mesh can be rebuilt as sketches you can change: see Make an STL editable.
  • Insert a model… (or Add on the Insert tab) adds a model from a file into the current project instead of opening it.
  • Projects folder…: the folder Open and Save start in (on this computer; not on a 3DJames box).
  • The name of the project and whether it has unsaved changes show at the top of the window.

Saving for printing and other programs

In Save as…, pick the type (in the "Save as type" list):

  • 3DJames project (.3dj): everything stays editable. The one to keep.
  • 3MF: for your slicer, with colors and separate objects. It also carries the editable project, so 3DJames opens it again with its history.
  • STL: the finished shape only, for any slicer.
  • STEP: exact solids for other CAD programs (imported meshes and threads are left out).
  • STL and STEP keep only the shape: after saving one, your project is still open as before, and Save (Ctrl+S) still saves your project file. If you haven't saved the project yet, 3DJames still reminds you.
  • Check that it fits your printer with View > Printer area, and turn the side that should lie on the bed down with Lay flat on a face (Object > Faces).
  • Older 3DJames projects saved as .json still open; save them again as .3dj.

Backups and versions

  • Your work is copied in the background as you go: ☰ > Backups… lists the recent copies (kept in this browser). Restore one to get back work you didn't save.
  • Backups stay in this browser only. Save a project file to keep your work for good and to take it to another computer.
  • Named milestones inside a project: Versions.

On a 3DJames box

When you use 3DJames from a 3DJames box (http://3djames.local), Open and Save show your folders on the box instead of this computer's, and Sign out is in the File menu.
