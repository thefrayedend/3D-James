Tutorial: a mug from two sketches

You will learn: drawing a wall cross-section, rounded sketch segments, revolving, an extruded handle, exact placement and Merge. This example is a 90 mm tall hollow mug with 80 mm outside diameter, a 3 mm wall, and a 5 mm floor.

1. Draw the cup cross-section

Save your current work and start a new project. Choose Insert → Sketch → On the floor. Draw a closed seven-point outline on the right of the green line. Select the outline in Shapes and enter the coordinates below. These are radius and height, not the full cup width.

Close back to P1. For the rounded outside base in the example, select the diagonal P2–P3, choose Bend, then set its Radius to 4. Use Flip bend if your arc goes into the wall instead of following the outside corner.

2. Spin it into a hollow cup

Choose Done → Spin around, angle 360°, Result New object, then OK. The green sketch line is the rotation axis. Do not center this outline across it: the entire outline must stay on one side.

3. Sketch a handle with an opening

Return to Sketch → On the floor. Draw two closed six-point outlines, entering the coordinates below. The inner outline becomes the handle opening. For both outlines, Bend segments P2–P3 and P4–P5; set Radius to 10 outside and 4 inside.

4. Stand the handle up and position it

Choose Done → Push up, Height 10 mm, Result New object. Select the handle. In Properties set Rotation to X 90°, Y 0°, Z 0°. Set Position of the middle to X 54, Y 0, Z 47.5 mm. The handle now lies in a vertical plane beside the cup. You do not need a tangent plane for this full handle.

5. Merge and inspect

Select the cup first, then Ctrl-click the handle. Choose Object → Merge, inspect the preview, and Apply. Orbit to check the open top and handle. Save a .3dj project.

Change the example

In History, Revolved cup profile → Edit sketch changes the cup; Rounded handle profile changes its outline, thickness and placement. Try handle Height 12 mm instead of 10, then Undo. The merge rebuilds from the changed sketches.

These outlines are editable, but not fully constrained. Changing one point does not automatically maintain every wall thickness or handle connection. If you change the cup radius, adjust the handle's placement and overlap too. Failed or suppressed earlier steps can invalidate later joins. A smooth sculpted blend at each handle joint and ceramic glaze are separate refinements; this example does not reproduce the photograph's finish.
