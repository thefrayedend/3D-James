Mouse and keys

Left-drag (empty space)Turn the view
Right-drag or middle-dragSlide the view
WheelZoom
Double-click an objectFly in to it. Double-click it again: twice as close. A third time: back to the first view
Ctrl + clickPick more than one
Drag an object (Alt: no snapping)Slide it on the floor
Shift + drag an objectLift it up or down
Drag a shape button into the viewAdd the shape where you let go (click it: beside the others)
Ctrl+Z / Ctrl+YUndo / redo
Ctrl+S / Ctrl+Shift+S / Ctrl+OSave / Save as / Open
Ctrl+C / Ctrl+V / Ctrl+DCopy / paste / duplicate
Ctrl+G / Ctrl+Shift+GGroup / ungroup
DeleteDelete
Arrow keys, Page Up/DownNudge (Shift = 10×)
M / R / SMove / Turn / Size handles
DDrop to the floor
F / HomeFit in view / start view
EscStop a tool, or unpick

Tablets and the Apple Pencil: see Tablets and Apple Pencil for the finger and pen versions of all of this.

Shift while drawingStraight or 45° (rectangle: square)
Near a loose end: pull backThe end lets go: place the point anywhere near it (come back in to grab it again)
Alt while drawing or draggingLoose ends reach 10 mm instead of 2 mm (the dashed circles show how far)
Ctrl while clicking or draggingPlace the point exactly where the pointer is (no snapping at all)
Type a number + EnterExact length or size
Enter / Esc / double-click while drawing a lineStop here: the line stays (unfinished); carry on later from its orange end
Ctrl+Z while drawing a lineTake back its last point
Shift+click (Select)Pick more than one side, point or shape
Double-click a sideAdd a corner there
Wheel / right-dragZoom / slide the board
DeleteDelete the picked corner or shape. A picked side opens the outline so you can draw a new part in its place
