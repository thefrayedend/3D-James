3DJames - open-source parts and their licenses
==============================================

3DJames itself is licensed under the GNU GPL version 3 or later (3DJames-GPL-3.0.txt).

3DJames is built on these open-source projects. Each one's license text is in this folder,
and the same list is inside the app: Help tab > About / Licenses.

  OpenCascade Technology (OCCT) .... LGPL 2.1 ................. opencascade-LGPL-2.1.txt
  replicad ......................... MIT ...................... replicad.txt
  opentype.js (inside replicad) .... MIT ...................... opentype.js.txt
  Flatbush (inside replicad) ....... ISC ...................... flatbush.txt
  Manifold ......................... Apache 2.0 ............... manifold-Apache-2.0.txt
  three.js ......................... MIT ...................... three.js.txt
  Lucide icons ..................... ISC ...................... lucide.txt
  DejaVu Sans Bold font ............ Bitstream Vera / Arev .... dejavu-fonts.txt

  bd_vslot (V-slot dimensions) ..... MIT ...................... bd-vslot.txt

About OpenCascade (LGPL 2.1)
3DJames uses OpenCascade, compiled to WebAssembly by the replicad-opencascadejs project, without
changes. You are free to use a modified version of it instead. Its source code is at
https://github.com/Open-Cascade-SAS/OCCT and https://github.com/sgenoud/replicad.
The source code and build script of 3DJames, which let you rebuild 3DJames with your own
OpenCascade build, are available from the person who gave you 3DJames, on request, for at least
three years after you received it.
