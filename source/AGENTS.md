# Project requirements

When changing behavior that a user needs to learn, update the in-app Help in the
same change. Explain how to start the tool, a small worked example, how to finish
or cancel, and its material limitations. Use screenshots from the real app when
they clarify the workflow; include useful captions and alternative text.

Check existing Help topics for obsolete names and instructions. Rebuild the HTML
so the written help and pictures are embedded and work offline. Verify the Help
navigation, referenced images, and layout in the rebuilt app. Apply this rule to
future tool changes; help is part of completing the feature.
